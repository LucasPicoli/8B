# pt-BR glossary

The tone and the terms of `LC_MESSAGES/gui.po`. Read this before you change a translation, and
keep a new string in line with it. A contributor who adds another language can copy this file
as a pattern.

## Tone

- Address the user as "você", and drop the pronoun when the sentence reads without it ("Conecte
  o controle", not "Você deve conectar o controle").
- Instructions to the user take the imperative: "Conecte", "Execute", "Mantenha".
- Buttons and menu items take the infinitive, as KDE, GNOME and Microsoft pt-BR do: "Salvar",
  "Cancelar", "Gravar no controle".
- Sentence case, “ ” quotes and the "…" ellipsis carry over from English.
- No article before the name of any app or program, 8B included: "8B não conseguiu…",
  "Reinicie 8B.", "pkexec não está instalado", "{name} também está usando o controle".
- "novamente", never "de novo": "Tentar novamente", "Gravar novamente".
- "via USB", never "por USB".
